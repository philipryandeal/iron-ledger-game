# The Ten Rooms

*One architecture, many theologies. Ten chambers, twenty-two postings between them.*

The Iron Ledger keeps its own idiom — no borrowed maps, no borrowed letters. Ten rooms of the books, each a station; the paths between them are **postings**, small transactions of the soul, each a meditation on movement. Debited from one chamber, credited to the next.
