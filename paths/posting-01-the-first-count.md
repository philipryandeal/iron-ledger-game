# Posting 01 — The First Count

**From:** Room 01 — The Widow's Pantry
**To:** Room 02 — The Counting Room

*Every path is a posting: debited from one chamber, credited to the next. Walk it slowly. Nothing here is scored.*

---

What is kept must first be counted. The Keeper carries the jars' tally from the shelf to the till and learns the first arithmetic of the house: keeping is not the same as knowing. Count them. Count them again. The second count is the true one.

---

*The books remember the crossing, even if the Keeper forgets.*
